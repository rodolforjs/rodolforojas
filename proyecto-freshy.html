FRESHY

Ventilación automatizada con sensores.

Maqueta de representación

FRESHY

2024

CONTEXTO

Este proyecto fue desarrollado como parte del desafío de Taller I, el cual consistía en cuantificar variables no visibles en el ambiente y presentarlas al usuario mediante un sistema interactivo. La propuesta consiste en un sistema que mide y controla de manera automática las variables de temperatura y humedad en un espacio.

A través de un dispositivo central, el usuario puede visualizar estos datos en tiempo real, mientras dos extractores independientes regulan cada variable por separado para mantener condiciones óptimas.
